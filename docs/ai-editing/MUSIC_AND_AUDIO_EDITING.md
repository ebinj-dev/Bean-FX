# Music And Audio Editing (M42-C)

Recipes: see STYLE_CATALOG.md / scripts/ai-editing/style-recipes.json (music-video-montage).

The track is the spine: section boundaries map to song structure (intro/verse/chorus/bridge), cuts land on transients (beat analysis when the tool is installed — disclosed otherwise), holds sit on the downbeats of section changes.

The energy curve of the cuts must match the song's. Karaoke captions need aligned lyric timing — disclosed when absent.

**Execution contract:** everything described maps to real editor capabilities or is disclosed via the capability matrix (STYLE_CAPABILITY_MATRIX.md). Nothing in this file instructs RIISHE to fake an unsupported effect.
